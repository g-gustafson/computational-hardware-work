# computational-hardware-work
This is a repository that contains to peices of work that myself and a few others did during a Computational Hardware Class


Project 1: (ran and tested in QTSPIM)
-A text-based adaptation of the solitary card game Scoundrel. (Rules can be found here https://scoundrelthegame.com) \
-I worked with a group to develop the game in assembler.\
-The pseudo code was all me and the shuffle function was also all me. \
  the game was never fully finished as the class did not require the game to be finished however I still believe it demonstrates a good level of understanding.\
-I learned that it is incredibly important to fully understand the limitations of your systems so you can plan and work within its limits and plan accordingly. I also learned once again that documentation is incredibly important especially the code comments as going back to edit the code or having team mates work on requires fine detail laid out.

Final project: FP3_jghc is the folder (ran in vivado 2025.2)
-I worked with my group to make an custom micro processor and simulate it in vivado. As a joke we named the processor Greg (this turned out to be an 
  annoying choice but gave us a few laughs) \
-We used VHDL to code in vivado and used Lua to make an assembler to turn our code into hexadecimal and then binary for our processor. \
-I had lots of help and we worked as a team in order to make this happen. \
-What I leaded the most was that i need to ask for help when I didn't understand what was happening. The result of me not doing that was wasting a lot of time trying to figure out things on our own. I however have leaded from this the importance of asking for help and planning everything out in advance in super fine detail.
